## Edit and build

`content.html` contains the converted source body. Edit it and run `python build.py` to regenerate `index.html`. `source-manifest.json` records the section headings, source fingerprint, image inventory, and privacy exceptions. Keep its navigation entries synchronized when changing headings. `GUIDE.md` is a parallel readable source export and must be kept synchronized when editing content.

Run `python build.py` using Python 3.12 or later; the build has no third-party Python dependencies. Every push to `main` rebuilds and publishes the guide with GitHub Actions. The generated website uses relative asset links so it can be copied or transferred to another repository; enable Pages there and update the repository links.
