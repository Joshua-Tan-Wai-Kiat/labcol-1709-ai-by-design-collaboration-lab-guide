## Edit the guide

Edit `GUIDE.md` using GitHub’s pencil button and commit to `main`. GitHub Actions rebuilds and publishes the website automatically. To preview locally, run `python build.py` and open `index.html` in a browser.

## Publishing

In Settings > Pages, choose GitHub Actions. The workflow builds from GUIDE.md without external Python packages. The repository has no hardcoded site base URL in its generated page, so it can be copied or transferred; update the README link and enable Pages at the destination.
